# Documentation

## Architecture

### Blockchain Engine

Le moteur de blockchain gère la structure des blocs, la validation des transactions et le state management.

### Consensus

L'algorithme de consensus suit le modèle Proof-of-Authority de PulseChain avec des paramètres de fork spécifiques.

### Ledger

Le registre suit le modèle de compte d'Ethereum avec des soldes ETH et des tokens PRC-20.

### RPC Server

Le serveur RPC fournit une interface JSON-RPC compatible avec les clients Ethereum (geth, metrics).
